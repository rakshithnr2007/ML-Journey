# NumPy Basics 🔢

Documentation of core **NumPy** concepts in Python, covering array creation, indexing, reshaping, and mathematical/matrix operations.

## What's inside

The notebook (`numpy_Basics.ipynb`) covers:

- **Array Creation** – creating arrays, `.dtype`, `.shape`, `.size`, `.ndim`
- **Indexing & Slicing** – slicing, negative indexing, reversing an array
- **NumPy Axis** – summing along rows vs columns (`axis=0`, `axis=1`)
- **Conversion from Python Structures** – building 3D arrays from nested lists
- **Intrinsic Array Creation Functions** – `zeros()`, `arange()`, `linspace()`, `empty()`, `identity()`
- **Reshaping & Flattening** – `reshape()`, `ravel()`
- **Combining Arrays** – `concatenate()`, `vstack()`, `hstack()`
- **Random Arrays** – `np.random.rand()`
- **Miscellaneous Functions** – `argmin()`, `argmax()`, `min()`, `max()`, `mean()`
- **Matrix Operations** – element-wise `+ - * /`, modulus, `sqrt()`, `where()`, `count_nonzero()`, transpose (`.T`), and true matrix multiplication (`@`) vs element-wise multiplication (`*`)
- **Memory & System Info** – comparing memory usage of a Python list vs a NumPy array using `sys.getsizeof()` and `.itemsize`
- **Meshgrid** – converting two 1D arrays into 2D coordinate grids with `np.meshgrid()`
